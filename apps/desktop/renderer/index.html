    Recovery

    Always-on relay

    A computer you leave on keeps encrypted copies it can’t read, of documents and uploaded files alike, so your files and your computers sync even when nothing else is online. New files you make use it.

      Network

      Bootstrap addresses

      The first time it goes online, commonplace finds the network through a few public bootstrap addresses. After that it starts from computers it has already met. A group can also run its own bootstrap node and list it here, one host:port per line.

      Changes apply the next time commonplace starts. Computers on the same Wi-Fi or network always find each other directly, with or without these.

      Right-click a word underlined in red for suggestions. On Windows and Linux the dictionary for your language is downloaded once; nothing you write is sent anywhere.
